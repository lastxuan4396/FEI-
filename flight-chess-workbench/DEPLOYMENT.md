# 公网发布与双人联机

公网地址：https://flight-chess-online.onrender.com/

代码仓库：https://github.com/lastxuan4396/flight-chess-online （私有仓库）。与 OH Card 使用同一个 Render 工作区，但运行独立服务。

部署方式：GitHub 私有仓库 + Render Node Web Service。构建命令 `npm ci --include=dev && npm run typecheck && npm run build`，启动命令 `npm run serve`，健康检查 `/healthz`。服务监听 `0.0.0.0`，使用平台提供的 `PORT`。

进入网站，选好地图和题库，再点击“ 双人联机 · 用当前地图建房”。将“复制邀请链接”得到的链接发给另一位玩家。两人分别保留各自的链接；邀请链接含加入房间的凭证，请只发给参与者。

原六种棋盘和上传的图片棋盘共用房间：服务器处理骰子、回合权限、任务计时与确认。全屏保留骰子、计时、撤销和房主随机刷新。随机刷新保留路线，并从本局冻结的题库重新分配任务、重开两人的进度。联机进度不会覆盖浏览器原有个人题库或本机存档。

附带27张原图棋盘及已整理地图；识别不清的内容仍需两人对照原图确认。公网部署不包含本机Python OCR环境，上传图片仍可编辑；不要将可读地图数量当成自动识别准确率。

免费 Render 服务约15分钟无人访问会休眠，下一次打开可能等待约1分钟。没有持久数据库时，服务休眠、重启或重新发布会清空联机房间；两人需要重新建房。浏览器中的本机题库和本机对局独立保留。本次配置仅创建免费服务，没有配置付费磁盘或付费数据库。

当前验证：400项Node规则/API测试、typecheck、lint及生产构建；独立390px与1280px浏览器验证邀请、回合权限、任务开始/暂停/完成、刷新保持截止时间、房主随机换题、全屏共享计时、离开后个人存档保持。2026-10-11已用上述公网地址复测：两个独立浏览器会话验证邀请链接确实指向公网、回合和目标计时权限、刷新重连与计时截止时间、完成任务同步、随机换题、全屏共享计时；三选一模式验证秘密提交、对方不可见、刷新角色恢复与完整结算。无浏览器脚本错误。此验证不冒充两部实体手机或不同运营商网络测试。
