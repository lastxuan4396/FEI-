## 已实现

- 新开局固定两位玩家，每人一个棋子；可修改名字、颜色和题库筛选。旧多人存档仍按原人数恢复。
- 六种参考版式：十字、空心螺旋、箭头岔路、折返长线、双起点内外圈、弯曲路线。每张玩法卡可选择原版或36、49、64、81、100、144、196、256格延伸；图形沿原玩法轮廓延伸，路线留白，长度不等于密铺方阵。另可选舒展折线与留白螺旋。JSON 可提供 2–16 行列、4–256 个格子的稀疏或矩形路线。
- 起飞可选“掷出 6 才起飞”；起飞成功仍在起点，再掷一次开始移动。
- 终点可选：超过后折返、超过即可获胜、恰好到达。
- 格子：任务、前进/后退、返回起点、再掷一次、暂停下一轮、下次翻倍、普通休息、起点和终点。
- 任务对象：当前玩家、下一位玩家、所有玩家；同一题库抽完前不重复。
- 任务必须先完成或跳过，才推进回合。跳过任务不额外惩罚。
- 三等级图片题库逐题修改、删除、恢复、添加自定义题目；等级可任意混选，随机混抽或仅抽勾选题目。旧主题放在折叠区域继续编辑。任务包仍支持创建、元信息编辑和JSON批量追加/替换；主题总计最多5000条任务。
- 当前任务、随机种子、抽取袋、胜者、回合、撤销记录和题库一起保存；刷新可继续。
- 最近 12 次操作可撤销；自动保留上一份可用存档。写入失败会提示导出。
- 使用 Web Locks（可用时）与修订号检查协调多标签页，避免旧窗口覆盖新状态；不支持 Web Locks 的浏览器只提供修订号检查和状态同步。
- 导出全部、导出棋盘、导入工作区/棋盘/底层对局存档。

六种棋盘共用可编辑的三等级图片题库；修改会用于新开局，进行中的任务与配置快照保持原样。原始图片内容与自定义修改分开保存，删掉的原始题目可以恢复。默认示例主题保留在折叠区域。主页可选择经典互动、螺旋竞速、岔路探险、合作闯关、双人追逐、随机事件六个模式。模式区别、图片机制参考和新增配置字段见 [modes.md](modes.md)。

## 操作

1. 主页选择玩法；卡片的路线长度菜单可预览延伸，再点“使用此棋盘”。在“题库”勾选等级，选择随机混抽或自选题目；详见 [棋盘与题库指南](board-and-library-guide.md)。
2. 点击“开始游戏”，轮流掷骰。任务卡点击翻转，完成或跳过。
3. 返回主页保留进度，点击“继续当前局”恢复。
4. 在“题库”页搜索、修改或删除图片题目，也可添加自己的题目；开局后修改题库只影响下一局。旧主题仍可在折叠区域编辑。
5. “导出全部”备份所有库和当前进度。“导出棋盘”生成可以手动编辑的配置；“导入文件”会替换当前设置和对局。

批量任务格式：

```json
{"tasks":["分享一件最近开心的小事。","各说一种喜欢的水果。"]}
```

批量导入保留了上游的“复制提示词”功能，供在外部 AI 使用；本应用不连接 AI 服务。

## 内容与规则如何扩展

`examples/board-6x6.json` 和 `examples/board-7x7.json` 是完整棋盘配置，可直接导入。

`layout.path` 在自动行走模式下按移动顺序存放 `[x,y]`。左上为原点，x 向右、y 向下；下标是格子编号。`tiles` 与路线等长，第一格 start、最后一格 finish。编号从 0 开始。默认蛇形走完一行后进入下一行。

```json
{"type":"task","deck":"talk","target":"both"}
```

上述格子抽取 `talk` 任务库并由所有玩家执行。`target` 也可为 `self` / `other`，`other` 在多人局表示下一位玩家。

```json
{"type":"move","steps":-3,"label":"退后三格"}
```

`move` 步数可正可负。负向移动到起点就停止；正向移动按终点规则处理。开启连锁后，移动到新的特殊格继续触发，检测到循环或达到 `maxChain` 上限就结束本次操作。折返经过终点不算获胜，最终停在终点才算。

任务有两种抽取模式：

- **按玩家**：每位玩家使用主页所选题库。共同任务使用当前玩家的题库；“对方任务”使用下一位玩家的题库。
- **按格子**：使用格子上的 `deck` 引用，可让不同区域抽取不同任务库。导入不含 `playerDecks` 的棋盘默认采用此模式。`examples` 使用此模式。在题库页修改对应任务库会影响下一次开局。

“玩家与规则”可切换模式。导出棋盘会保存当前模式对应的题库引用。每局开局时固定配置快照，编辑内容不会让当前任务和存档发生变化。

## 架构

```text
src/core/config.js       配置校验与默认模板
src/core/engine.js       纯状态转换、路线计算、格子与抽取规则
src/core/storage.js      底层对局存档格式、校验与备份
src/core/workspace.js    题库、设置和活跃对局的整体工作区
src/hooks/useGameState.ts  React 适配、存储、多标签页协调
src/components/         上游组件及本版本新增/修改的界面
```

`src/core/modes.js` 提供六个模式及内置任务库。岔路选择和计时器是可保存、可撤销的操作。

游戏规则通过 `transition(state, config, action)` 一次提交新状态。界面动画只显示结果，不逐步修改棋子或计算规则。要添加新格子：扩展 config 校验及类型、engine 落点分支、棋盘文案和对应测试。

存档与配置都是 JSON 数据，不执行其中的代码或 HTML。`window.render_game_to_text()` 输出可测试的当前状态；`window.advanceTime()` 在本回合制版本中不推进规则。
