# 八种玩法的双设备联机

网址：https://flight-chess-workbench.onrender.com/#games

转盘抽卡、卡牌对战、合作闯关、分支剧情、任务宾果、默契抉择、图片解谜、街区大富翁都可以创建双设备在线房间。新开局默认勾选“两台设备 · 在线房间”；也可以取消，继续同设备轮流玩。

先设置两人的名字、题库、地图和回合数量，开始后复制“对方邀请链接”。对方在自己的设备打开邀请；两人分别保留自己的页面链接，刷新即可恢复身份和进度。

地图浏览、缩放和输入草稿各自操作；骰子、分数、金币、地块、任务、计时、次数和持续效果共同保存。任务和卡片由对应玩家操作；共同任务可以由参与者确认。持续任务列在外侧，可以继续下一次抽取。服务器校准计时，避免设备时钟差影响倒计时。

大富翁保留购买、建造、收租、抵押和交易。竞拍由当前出价者操作，交易由买方确认；合作合约需要对方在自己的设备接受。默契投票可以同时独立提交，双方提交之前隐藏对方的选择。对方手牌及谜题答案也由服务器隐藏。

在线进度与本机存档分开。在线局通过自己的房间链接恢复，不能把隐藏过的手牌导出为完整本机存档。返回大厅或离开房间不会替换已有本机进度；重新开局会建立新房间。

现有七个任务出牌版本、普通及图片棋盘的联机入口继续保留。原图内容和识别核对状态没有因联机更新而改写。

免费服务首次打开可能需要等待唤醒。房间七天无操作失效；网页服务重新部署可恢复房间，但免费 Key Value 自身重启可能清空数据，不作为永久存档。没有启用付费资源。

开发接入：`/api/arcade-rooms` 独立路由，Redis 使用 `paired-workbench-v1:arcade`；原 `paired`、`board` 命名空间保留。服务器检查角色、版本和操作编号，断线重试使用原编号，避免重复发放奖励或扣款。
